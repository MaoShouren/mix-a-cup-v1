# 调一杯：独立部署版本

此版本包含 34 款配方、33 张内置实拍照片、搜索筛选、设备收藏及照片评论。页面和图片不向 chatgpt.site 请求数据，评论也使用同一个独立服务。

## 状态

代码及本地功能已验证。尚未部署到新的公网服务器，尚未在用户 iPhone 上验证。该迁移不能保证新托管域名在所有网络可访问。

## 本地运行

需要 Node.js 22 或更新版本，无需安装依赖。

```sh
npm start
```

浏览器打开 http://localhost:3000 。`npm test` 运行检查。

## 部署到 Node 或 Docker 托管服务

- 启动命令：`npm start`。
- 健康检查路径：`/healthz`。
- 服务读取平台分配的 `PORT`，监听 `0.0.0.0`。
- 托管平台应在入口终止 HTTPS，转发 `Host` 和 `X-Forwarded-Proto: https`。评论提交保留同源检查。
- **持久保存照片及评论必须挂载持久磁盘**，并将 `DATA_DIR` 设置为该挂载目录，如 `/var/data/mix-a-cup`。默认 `./data` 仅适合本地或已有持久文件系统；云平台临时磁盘在重建后可能丢失数据。
- 若平台的磁盘或服务需要付费，选择套餐前先确认费用；此包不会开通或购买任何服务。
- 旧站云端评论不会自动迁移。旧站数据保持原位，需另行导出后迁入，避免承诺跨平台自动同步。
- 当前展示最近存储列表中的至多 200 条评论，适用于小规模体验；大规模社区需接入数据库、分页、用户登录、审核及限流。

## iPhone

新地址经 iPhone Safari 验证可访问后，再选择“分享 → 添加到主屏幕”。这是网页应用，不是已签名的 iOS 安装包。

## 配方与照片来源

配方参考 IBA / TheCocktailDB，并整理为中文居家版本；每个酒款详情列出来源链接。照片为公开资料中的实拍参考；无酒精青柠薄荷气泡使用同风格参考照片。正式商业分发前需核对每张照片的授权及数据源使用条件。
